# product-feature-dropoff-analysis-sql
SQL project to identify product features that users try once and abandon, helping product teams improve feature adoption and user engagement.


# Product Feature Drop-Off Analysis using SQL

## 📌 Business Problem
Many users try a product feature once and never return.
This project identifies features with high drop-off rates so product teams
can improve usability, onboarding, or value communication.

## 🧠 Approach
1. Track first and last usage per user per feature
2. Identify users with only one interaction
3. Calculate feature-wise drop-off percentage
4. Rank features by abandonment severity

## 🛠 SQL Concepts Used
- Aggregations
- CASE statements
- Window functions (RANK)
- CTEs

## 📊 Key Metrics
- Total users per feature
- Dropped users
- Drop-off percentage
- Feature priority ranking

## 💼 Business Impact
- Improves feature adoption
- Helps product roadmap decisions
- Reduces churn caused by poor feature experience

## 🎯 Ideal For
- Product Analyst roles
- Data Analyst roles
- SaaS / Fintech / App-based products
